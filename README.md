# Simple Stock Flow — Laravel API

This repository owns the PHP backend, including the domain and application layers, persistence adapters, HTTP API, and backend tests.

## Current scaffold

- `laravel-phase-3/` contains the earlier application-layer reference implementation.
- `laravel-phase-4/backend/` contains the persistence and PHPUnit reference scaffold.

These phase scaffolds have been moved here from the workspace's former `app` location. They are not yet a complete bootable Laravel application. Phase 5 will add the HTTP API in this repository; Docker orchestration and container execution remain deferred to Phase 7.

The authoritative business rules and API contract are maintained in the documentation repository.
